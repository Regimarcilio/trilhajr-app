## 3. DETALHAMENTO DAS VULNERABILIDADES

### A01: Broken Access Control - CORS Aberto
**OWASP:** A01:2025 | **CWE-942**  
**Severidade:** CRÍTICO → HIGH  
**Status:** NÃO BLOQUEANTE (em staging, mas bloqueia merge em produção)

**Evidência:**
```
arquivo: backend-api/src/index.ts
linha: 12
código: app.use(cors({ origin: '*' }));
```

**Impacto:** 
Permite que qualquer origem (mesmo maliciosa) acesse os endpoints da API, incluindo upload de PDFs e gerenciamento de pagamentos. Vulnerabilidade de Cross-Origin Resource Sharing abusivo.

**Correção:**
```typescript
// 1. Listar origens permitidas
const ALLOWED_ORIGINS = [
  'https://trilhajr.app',
  'https://www.trilhajr.app',
];

app.use(cors({ 
  origin: (origin, callback) => {
    if (!origin || ALLOWED_ORIGINS.includes(origin)) {
      callback(null, true);
    } else {
      callback(new Error('Origin not allowed by CORS'));
    }
  },
  credentials: true,
}));
```

**Esforço:** MÉDIO  
**Recomendação:** Implementar antes de qualquer deploy

### A04: Injection - Validação Insuficiente de PDFId
**OWASP:** A05:2025 | **CWE-20**  
**Severidade:** MÉDIO  
**Status:** NÃO BLOQUEANTE

**Evidência:**
```
arquivo: backend-api/src/routes/index.ts
linhas: 17-19, 22-28, 49-82
código: Parâmetros não validados
```

```typescript
// Sem validação de tipo ou formato
router.get('/pdf/:id/status', (_req, res) => {
  res.json({ status: 'uploaded', id: _req.params.id });
});

router.get('/pdf/:id/download', (_req, res) => {
  res.download('./uploads/sample.pdf', ...);
});
```

**Impacto:**
- Path Traversal possível via parâmetro `id` não sanitizado
- Injeção de caracteres especiais poderia manipular caminhos

**Correção:**
```typescript
// Validar parâmetros
const pdfIdSchema = yup.string().uuid().required();

router.get('/pdf/:id/status', async (req, res) => {
  try {
    await pdfIdSchema.validate(req.params.id);
    // ... resto da lógica
  } catch (err) {
    return res.status(400).json({ error: 'ID inválido' });
  }
});

// Usar path.join com validação
const SAFE_ID = path.basename(req.params.id);
const filePath = path.join(uploadsDir, SAFE_ID);
```

### A05: Broken Authentication - Falta de Autenticação Real
**OWASP:** A07:2025 | **CWE-306**  
**Severidade:** MÉDIO  
**Status:** NÃO BLOQUEANTE

**Evidência:**
```
arquivo: backend-api/src/index.ts
linha: 17
código: app.use('/api', require('./routes').default);

arquivos: Todos os endpoints sem autenticação
```

**Impacto:**
- Endpoints de pagamento e download de PDFs públicamente acessíveis
- Nenhum verificação de sessão ou token de usuário
- Usuário pode baixar PDF de outro usuário via IDOR

**Correção:**
```typescript
// Implementar middleware de autenticação JWT
const authMiddleware = (req: Request, res: Response, next: NextFunction) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ error: 'Não autorizado' });
  
  try {
    const decoded = jwt.verify(token, JWT_SECRET);
    (req as any).user = decoded;
    next();
  } catch {
    return res.status(401).json({ error: 'Token inválido' });
  }
};
```

  id: string;

  consentGiven: boolean;

// Agendamento de limpeza automática
cron.schedule('0 2 * * *', async () => {
  const expired = await db.pdf.findMany({
    where: { expiresAt: { lt: new Date() } }
  });
  for (const pdf of expired) {
    await fs.unlink(pdf.path);
    await db.pdf.delete(pdf.id);
  }
