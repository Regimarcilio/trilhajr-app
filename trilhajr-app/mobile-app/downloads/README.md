## 📱 ANDROID - APK (MAIS RÁPIDO)

**CLIQUE PARA BAIXAR:**
```
https://github.com/Regimarcilio/trilhajr-app/releases/download/v1.0.0/recrutadornow-android.apk
```

**Manual:**
1. Clique no link acima
2. Toque em "Adicionar à armazenamento"
3. Abra `recrutadornow.apk` no celular
4. Toque em "Instalar"
5. Abra o app!

---

## 🍎 iOS - Expo Go

**ABRA NO EXPO GO:**
```
https://expo.dev/@trilhajr/recrutadornow
```

**Passo a passo:**
1. App Store → instalar "Expo Go"
2. Safari → abrir link acima
3. Toque em "Open in Expo Go"
4. Aguarde carregar (30 segundos)

---

## 💻 WEB APP (PWA)

**ACESSE:**
```
https://recrutadornow.com
```

**Instalar como app nativo:**
1. Abra no Chrome/Firefox/Edge
2. Toque no ícone "Instalar" 
3. Adicionar à tela inicial
