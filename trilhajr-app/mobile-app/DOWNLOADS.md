# 📱 TrilhaJr App - Download oficial v1.0.0

## 🚀 Como instalar

### Android
**Método 1 - Google Play Store (recomendado)**
- Em breve: `play.google.com/store/apps/details?id=com.trilhajr.app`

**Método 2 - APK direto**
```bash
# Download APK (debug - para testes)
curl -L -o trilhajr-debug.apk \
  "https://expo.dev/downloads/xxxx-xxxx-xxxx.apk"

# Instalar
adb install trilhajr-debug.apk
```

**Método 3 - Expo Go**
```bash
1. Instale Expo Go (grátis)
2. Escaneie QR Code: https://expo.dev/@trilhajr/trilhajr
3. App executa automaticamente
```

### iOS
**Método 1 - App Store (recomendado)**
- Em breve: `apps.apple.com/app/trilhajr/idxxxxxxxx`

**Método 2 - TestFlight**
```bash
1. Instale TestFlight (grátis)
2. Solicite acesso: dev@trilhajr.app
3. Baixe a versão beta
```

**Método 3 - Expo Go**
```bash
1. Instale Expo Go (grátis)
2. Escaneie QR Code: https://expo.dev/@trilhajr/trilhajr
3. App executa automaticamente
```

### Web (Chrome, Edge, Firefox)
```bash
# Acione diretamente no navegador
https://trilhajr.com

# Ou baixe PWA
```

## 🔧 Para desenvolvedores

```bash
# Clonar repositório
git clone https://github.com/Regimarcilio/trilhajr-app.git
cd trilhajr-app/mobile-app

# Instalar dependências
npm install

# Iniciar em modo desenvolvimento
npx expo start

# Build de produção
npx eas-cli build --platform [android|ios] --profile production
```
