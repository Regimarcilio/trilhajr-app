### 📱 Método 1: App Store / Play Store
**Android**: `play.google.com/store/apps/details?id=com.trilhajr.app`  
**iOS**: `apps.apple.com/app/trilhajr/idxxxxxxxx` (em breve)

### 🎯 Método 2: Expo Go (mais rápido!)
1. Instale Expo Go (Play/App Store)
2. Acesse: https://expo.dev/@trilhajr/trilhajr
3. Escaneie QR Code ou abra no app Expo

### 🌐 Método 3: Web PWA
Acesse: https://trilhajr.com  
Instale como PWA para usar offline!

## 🔧 Para Desenvolvedores

```bash
git clone https://github.com/Regimarcilio/trilhajr-app.git
cd trilhajr-app/mobile-app

# Instalar dependências
npm install

# Executar app
npx expo start

# Build produção (EAS)
npx eas build --platform [android|ios] --profile production
```
